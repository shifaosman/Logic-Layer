# Logic Layer

A **frontend portfolio / skill showcase** project: a premium, animated marketing site for a fictional brand called **Logic Layer**. It demonstrates modern UI craft, motion design, and structured layout—not a production product or backend.

## What this project shows

- Next.js App Router, TypeScript, and component-driven structure
- Tailwind CSS for a dark, layered, glassmorphism-heavy visual system
- Framer Motion for scroll reveals, counters, parallax, magnetic buttons, and an interactive layer diagram
- Responsive layout, accessibility touches (e.g. reduced-motion for parallax), and production-minded scripts

## Tech stack

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)

## Prerequisites

- Node.js 18+ (20+ recommended)
- npm

## Setup

```bash
npm install
```

## Run locally

Development server (port **3003**):

```bash
npm run dev
```

Open [http://localhost:3003](http://localhost:3003).

Other scripts:

| Command        | Description        |
| -------------- | ------------------ |
| `npm run build` | Production build   |
| `npm run start` | Run built app (3003) |
| `npm run lint`  | ESLint             |

## Environment

No API keys or `.env` are required for the current static marketing page. Keep secrets out of the repo; `.env` is gitignored.
